# موقع أويس بن أحمد

موقع شخصي عربي (RTL) مبني على هوية [rzgfolio.framer.ai](https://rzgfolio.framer.ai)
البصرية، والمحتوى والصور مستخرجة من [owwwais.com](https://owwwais.com).

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء للإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## الهوية البصرية

القيم أدناه مقروءة من التنسيقات المحسوبة للموقع المرجعي مباشرة، لا بالتقدير:

| العنصر | القيمة |
| --- | --- |
| خلفية الصفحة | `#F7F7F7` مع شبكة نقاط ثابتة |
| البطاقات | `#FFFFFF` |
| النص | `#1A1A1A` |
| أخضر / أزرق / برتقالي | `#11B77A` · `#1B5FFF` · `#FE7617` |
| الاستدارة | أزرار `1000px` · بطاقات `20px` · أقسام `32px` |
| العناوين | Thmanyah Sans Bold — ‎128px / 56px / 40px |
| النصوص | IBM Plex Sans Arabic |
| اللاتيني والأرقام | Fragment Mono |

عناصر مميزة منقولة عن المرجع: شبكة النقاط، الخطان الرأسيان اللذان يؤطران
العمود الأوسط، بطاقة الهوية العائمة بالصورة، وأزرار الحبّة (pill).

## الخطوط وميزة `ss01`

**خط ثمانية (Thmanyah Sans) يدعم `ss01`** — وهو ما يعطي الحروف النهائية
المرسلة التي طُلبت. تحقّقنا من ذلك عملياً بقياس عرض النص في المتصفح مع
تفعيل الميزة وبدونها:

```
أويس بن أحمد   382.6px  →  474.7px   (ss01 مفعّلة)
```

الميزة مفعّلة على كل العناوين عبر:

```css
.display {
  font-family: "Thmanyah Sans";
  font-feature-settings: "ss01";
}
```

> **الترخيص:** ملفات خط ثمانية نُزّلت من الشبكة التي يخدم منها الموقع المرجعي.
> يُرجى التأكد من رخصة الاستخدام التجاري قبل النشر النهائي.

> **تنبيه:** `Fragment Mono` لا يغطي العربية. استخدم `.mono` للنصوص اللاتينية
> والأرقام فقط، وإلا انكسر اتصال الحروف العربية.

## البنية

```
src/
  components/
    Motion.tsx    # Reveal · Counter · Marquee · Parallax · Magnetic
    Ui.tsx        # SectionHead (ظهور كلمة كلمة) · CircleBadge
    Header.tsx    # بطاقة الهوية + زر القائمة + قائمة ملء الشاشة
    Hero.tsx      # الاسم + الوصف + الأزرار + شريط الأدوات
    Work.tsx      # المشاريع العشرة بصورها
    About.tsx     # نبذة + الصورة + المنهجية + المسار
    Skills.tsx    # ثلاثة أعمدة ملوّنة
    Services.tsx  # لافتة دعوة + الخدمات
    Products.tsx  # الأنظمة الجاهزة
    Faq.tsx       # الأسئلة الشائعة
    Footer.tsx    # الأدوات + دعوة ختامية + التذييل
  data/content.ts # كل النصوص وروابط الصور
  index.css       # المتغيّرات والطبقات والحركات
public/img        # صور المشاريع من owwwais.com (webp)
public/fonts      # الخطوط مستضافة محلياً
```

كل النصوص في `src/data/content.ts` — عدّلها دون فتح المكوّنات.

### الصور

صور المشاريع مأخوذة من تخزين owwwais.com ومحوّلة إلى WebP
(‏5.9MB ← 168KB). المشاريع شعارات لا صور فوتوغرافية، لذلك تُعرض بـ
`object-contain` حتى لا يُقتطع أي شعار، والعنوان أسفل الصورة لا فوقها
(الموقع المرجعي يستخدم صوراً داكنة تسمح بوضع النص عليها).

## ملاحظات تقنية

- التنسيقات الأساسية داخل `@layer base` و `@layer components` حتى تتمكن أدوات
  Tailwind من تجاوزها (القواعد خارج الطبقات تتفوّق على الطبقات كلها).
- الحركات تحترم `prefers-reduced-motion` عبر `MotionConfig reducedMotion="user"`.
- اسم الموقع في الواجهة يُعرض ككتلة واحدة لا حرفاً حرفاً، لأن تقسيم العربية
  إلى عناصر منفصلة قد يكسر اتصال الحروف.
