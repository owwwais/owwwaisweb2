# موقع أويس بن أحمد — النسخة الثانية

موقع شخصي بالعربية (RTL) بتصميم مشرق وواسع، مع حركات ظهور مرتبطة بالتمرير.
المحتوى مستخرج من [owwwais.com](https://owwwais.com).

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء للإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## التقنيات

- **Vite** + **React 18** + **TypeScript**
- **Tailwind CSS v4** (عبر `@tailwindcss/vite`)
- **Motion** (Framer Motion) لحركات التمرير

## الخطوط

الخطوط مستضافة محلياً في `public/fonts` (لا اعتماد على Google Fonts وقت التشغيل):

| الخط | الاستخدام |
| --- | --- |
| IBM Plex Sans Arabic | النصوص والعناوين — نفس خط الموقع المرجعي |
| Aref Ruqaa | العناوين البارزة وبطاقات المشاريع — الحروف النهائية المرسلة |
| Fragment Mono | الأرقام والنصوص اللاتينية الصغيرة فقط |

### ملاحظة حول `ss01`

طُلبت ميزة `ss01` للحروف النهائية المرسلة. بعد فحص **جميع خطوط Google Fonts
العربية (٥٦ خطاً)** برمجياً عبر قراءة جدول `GSUB`، **لا يوجد أي خط منها يوفّر
`ss01`** — بما فيها Sakkal Majalla غير المتاح أصلاً كخط ويب مجاني.

لذلك تحقّقنا من الهدف نفسه (أناقة الحروف النهائية) عبر **Aref Ruqaa**، وهو خط
رُقعة بنهايات منسابة يعطي الأثر البصري المطلوب.

ومع ذلك، الميزة **موصولة مسبقاً** في `src/index.css`:

```css
:root {
  --arabic-features: "ss01" 1, "calt" 1, "liga" 1, "kern" 1;
}
```

فإذا أُضيف لاحقاً خط يدعم `ss01` (مثل خط تجاري مرخّص)، تُفعّل الميزة تلقائياً
دون أي تعديل في الكود. والخطوط التي لا تدعمها تتجاهلها بلا أثر.

> **تنبيه:** `Fragment Mono` لا يغطي الحروف العربية. استخدم `.u-mono` للنصوص
> اللاتينية والأرقام فقط، و `.u-meta` لأي نص عربي صغير — وإلا انكسر اتصال الحروف.

## البنية

```
src/
  components/
    Motion.tsx      # لبنات الحركة: Reveal · WordReveal · Counter · Marquee · Parallax · Magnetic
    Header.tsx      # رأس ثابت + شريط تقدم التمرير + قائمة الجوال
    Hero.tsx        # الواجهة الأولى
    Stats.tsx       # الأرقام مع عدّاد تصاعدي
    About.tsx       # نبذة + ما أقدّمه + كيف أشتغل
    Work.tsx        # المشاريع مع تصفية حسب التصنيف
    Products.tsx    # الأنظمة الجاهزة
    Experience.tsx  # المسار الزمني + المهارات
    Faq.tsx         # الأسئلة الشائعة
    Contact.tsx     # دعوة للتواصل + التذييل
  data/content.ts   # كل النصوص في مكان واحد
  index.css         # المتغيّرات والطبقات والحركات
```

### تعديل المحتوى

كل النصوص في `src/data/content.ts` — لا حاجة للدخول في المكوّنات.

## ملاحظات تقنية

- التنسيقات الأساسية موضوعة داخل `@layer base` و `@layer components` حتى تتمكن
  أدوات Tailwind من تجاوزها (القواعد خارج الطبقات تتفوّق على الطبقات كلها).
- الحركات تحترم `prefers-reduced-motion` عبر `MotionConfig reducedMotion="user"`
  إضافة إلى قاعدة CSS.
